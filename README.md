# Groq LLM Parameter Experiment

This experiment demonstrates the effect of different sampling parameters on Large Language Model (LLM) text generation using the Groq API.

## Model Used

Llama 3.3 70B Versatile

## Parameters Tested

- Temperature
- Top-P

## Requirements

- Python 3.11+
- openai
- python-dotenv
- Groq API Key

## Installation

```bash
pip install openai python-dotenv
